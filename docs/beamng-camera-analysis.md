## Что исправлено в alias

- Ссылки вроде `---@alias Color `api.Color.Red` | `api.Color.Blue`` обозначают значения констант, а не строковые шаблоны generic-типов.
- Поддержаны локальные значения, поля и вложенные поля таблиц, определения в другом файле и ссылка на локальную таблицу, к которой прикреплена аннотация.
- Сохраняются конкретные значения чисел, строк и boolean: посторонние значения по-прежнему отклоняются.
- Аннотация поля SDK, ссылающаяся обратно на alias, не мешает прочитать значение константы.
- Область видимости берётся в месте определения alias. Циклы не приводят к бесконечному разрешению ссылок; изменённые зависимости пересчитываются.
- Захват generic-типа через обратные кавычки сохранён. Обычный alias не начинает автоматически разрешать комбинации флагов.

**Исправление прежнего вывода отчёта:** ссылки на значения в обратных кавычках документированы в [LuaCATS, @alias](https://luals.github.io/wiki/annotations/#alias). Это не частное расширение SDK. В этих 16 случаях недостаточной была поддержка LuaCATS анализатором; менять SDK для обхода проблемы не требуется.

## Ранее исправленные ошибки анализатора

- Исключённый nil учитывается при проверке полей pose/car в аргументах.
- Повторное присваивание полю сохраняет объявленный number после записи нуля.
- Обычный массив не связывается с посторонним предшествующим классом.
- ac.storage признаётся вызываемым по найденным сигнатурам.
- Неизвестное присваивание не восстанавливает прежний nullable-тип obsShot.
- @class на поле пространства имён учитывается аналогично локальному объявлению.
- Явный @type не теряется из-за nil-заглушки ac.Camera; действительно nullable-объявления сохраняются.

Предыдущие подозрения на необходимость исправлять ac.storage и ac.Camera в SDK сняты минимальными воспроизведениями и тестами анализатора.

Отдельно: отсутствие предупреждения accessMouseDelta не доказывает наличие API в подключённом SDK. В `ac_chaser_camera` его объявления нет; набор API приложения отличается от chaser-camera. Это не входит в оставшиеся шесть диагностик.
